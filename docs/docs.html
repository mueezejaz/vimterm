vimterm

A Vim-like terminal emulator for Windows.

vimterm spawns a shell (PowerShell, cmd.exe, WSL, ...) inside a Windows ConPTY, renders its output through a built-in VT emulator, and lets you drive the terminal with modal Vim-style keybindings. Navigate the screen and scrollback, search, yank and paste, record macros — all while the shell keeps running underneath.

Requirements

  • Windows 10 version 1809 or later (ConPTY API)
  • If building from source: Go 1.26+

Installation

Pre-built binary

Download the latest vimterm.exe (or the zip archive) from the Releases page. Your config file is created automatically on first launch at %APPDATA%\vimterm\config.toml.

Building from Source

git clone https://github.com/mueezejaz/vimterm.git
cd vimterm
go build -o vimterm.exe .

Usage

vimterm [options]
  -config path   path to config file (default: %APPDATA%\vimterm\config.toml)
  -shell prog    shell program to launch (overrides config)

Quit with ctrl+q or :quit.

Configuration

The config file lives at %APPDATA%\vimterm\config.toml and is created with all defaults and comments on first launch. Editing it reloads keybindings and colors live (checked once per second); other settings apply on the next launch.

Tip: The config is a standard TOML file. Any keybinding section you define fully replaces the defaults for that mode — partial overrides are not supported.

Full example

[general]
shell = "pwsh.exe"
shell_args = ["-NoLogo"]
scrollback = 20000
leader = "space"
timeoutlen = 1000
status_merge = "auto"

[colors]
status_fg = "#00ff87"
status_bg = "#262335"

[commands]
clean = "leader+c"

[cursor_trail]
enabled = true
duration = 300
opacity = 0.6
easing = "ease_out"
glow = 0.3
color = "#2dd4bf"

[keybindings.normal]
"leader+c" = "scroll_up"
"ctrl+y" = "scroll_down"
"$" = "move_line_end"

[keybindings.insert]
# only esc and ctrl+q are bound by default; all other keys pass through

[keybindings.visual]
"y" = "yank"
"d" = "yank"

General Options

KeyDefaultDescription
shell"powershell.exe"Program launched inside the terminal
shell_args[]Extra arguments passed to the shell
scrollback10000Max scrolled-off lines kept in memory
leader"space"Leader key token for bindings (e.g. "space" → Space key)
timeoutlen1000Milliseconds a partial key sequence waits before being discarded
status_merge"auto"Full-screen app status bar merging: "auto", "always", or "never"

Status merge modes

  • "auto" — merges only when the child's bottom row looks like a status line (e.g. nvim)
  • "always" — unconditionally overlays vimterm's status bar on top of the child
  • "never" — keeps vimterm's bar below the child (child gets hostRows-1 rows always)

Colors

Status line colors accept #rrggbb hex values. An empty string uses the terminal default.

KeyDefaultDescription
status_fg""Status line foreground color
status_bg""Status line background color

If both are unset, the defaults are fg={235,235,255} bg={40,40,90} (slate blue theme).

Custom Commands

Map any colon-command name to a key sequence that is replayed through the keybinding engine:

[commands]
clean = "leader+c"   # :clean now runs leader+c
reset = "ctrl+u"     # :reset runs ctrl+u

Built-in colon-commands cannot be overridden (see Colon Commands).

Modes

vimterm has four modes, mirroring Vim:

ModeLabelBehavior
NormalNORMALNavigation and control; keys go through the keybinding engine
InsertINSERTKeys pass through to the shell verbatim
VisualVISUALCharacter-wise selection; movement extends the selection
Visual LineVISUAL LINELine-wise selection

Token Syntax

Keybinding tokens follow this syntax:

SyntaxExampleDescription
Single keyh, G, f5One key press
SequenceggTwo keys typed in order
Modifiersctrl+u, shift+tab, alt+xModifier + key
Named keysesc, enter, backspace, tab, up, down, left, right, home, end, pageup, pagedown, insert, deleteSpecial key names
Leaderleader+tResolves to the configured leader key + t
Uppercase/punctuation:, YImplies shift

Chains

The value side can be an action name or an ordered list (chain) of action names:

"leader+nt" = ["new_tab", "rename_prompt"]   # open a tab, then ask for its name
"cos" = ["clear", "shell"]                   # wipe scrollback, restart the shell

A chain stops early if a step opens a prompt (the prompt takes over all input until committed or dismissed); every other step always runs.

Disabling bindings

Set the value to an empty string to remove a default binding:

"ctrl+q" = ""   # disable the default quit binding

Tabs

Each tab runs its own shell. Output keeps accumulating while a tab is in the background.

BindingAction
gtSwitch to next tab (3gt jumps to tab 3)
gTSwitch to previous tab
leader+ntOpen new tab and prompt for a name
leader+ttOpen tab switcher popup (type to filter, enter to select)
:rename <name>Name the current tab (shown in status line)
:close / :tabcloseClose the current tab
ctrl+wClose current tab

Tab labels truncate at 8 characters. Closing the last tab exits vimterm.

Search

  • / opens the incremental search prompt. Type your query and press enter to confirm, or esc to cancel.
  • Matches are highlighted as you type.
  • n jumps to the next match, N to the previous.
  • :noh or :nohlsearch clears the search highlighting.

Macros

  • q starts recording (the status line shows RECORD). Press q again to stop.
  • @ plays back the recorded macro.
  • With a count prefix (5@q), the macro plays N times.

Mouse Support

  • Click — positions the cursor
  • Drag — builds a character-wise selection
  • Double-click — selects a word
  • Scroll wheel — scrolls up/down
  • VT passthrough — when the child process requests mouse tracking (e.g. nvim), mouse events are forwarded as VT escape sequences

Cursor Trail

An optional animated cursor trail (smear effect) renders fading ghost cursors using Unicode braille (2x4 sub-cell dots per cell) for smooth diagonal rendering, with quarter-cell block fallbacks.

[cursor_trail]
enabled = true
duration = 300       # how long each ghost lives (ms)
opacity = 0.6        # max opacity of newest ghost (0.0-1.0)
max_positions = 40   # ring buffer capacity
easing = "ease_out"  # "linear", "ease_in", "ease_out", "ease_in_out"
color = ""           # trail color (#rrggbb), empty = terminal default fg
glow = 0.3           # glow intensity (0.0-1.0), blends toward white

Status Line

The status line at the bottom shows:

  • Current mode (NORMAL, INSERT, VISUAL)
  • Transient messages (search results, macro state, etc.)
  • Shell name
  • Cursor position (row, col)
  • Tab labels (when multiple tabs are open)

Wide Characters

Double-width CJK characters are correctly handled: cursor snapping, line editing, and display width calculations all account for characters that occupy two terminal columns.

Architecture

The data flow:

main.go → app.Run()
  ├─ Console input events → keybind engine → action map → PTY session writes
  └─ PTY output → emulator (VT parsing) → renderer → dirty-flag frame drawing
  • ConPTY — wraps the Windows ConPTY API for process creation and I/O
  • Emulator — built-in VT parser that processes ANSI escape sequences into a cell grid
  • Renderer — diffs consecutive frames and writes only changed cells to the host console
  • Keybinding engine — trie-based matcher with timeout for multi-key sequences
  • Search — incremental matching with highlight tracking across scrollback
  • Selection — character-wise and line-wise with clipboard integration via Win32 CF_UNICODETEXT
Note: vimterm wraps all shell commands in chcp 65001 for UTF-8 codepage support on Windows. This prevents mojibake in ConPTY output.
