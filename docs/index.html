Your terminal,
Vim-powered.

A native Windows terminal emulator with modal Vim keybindings. Navigate, search, yank, paste, record macros — while your shell keeps running underneath.

⌘

Modal Editing

Normal, Insert, Visual, and Visual Line modes. The keybindings you already know, right in your terminal.

⚡

ConPTY Native

Built on Windows ConPTY. Full UTF-8 support, proper process lifetime, and seamless shell integration.

⟳

Scrollback & Search

10,000+ lines of scrollback. Incremental search with highlighting. gg, G, ctrl+u/d to navigate.

⊞

Tab Management

Multiple shell sessions in tabs. Named tabs, filterable tab switcher, background output accumulation.

◉

Visual Selection

Character-wise and line-wise selection. Yank to clipboard, paste anywhere. yy, dw, p.

↻

Macros & Repeat

Record complex sequences with q, replay with @. Repeat the last action with .

✎

Fully Configurable

TOML config with live hot-reload. Rebind any key, remap leader, define custom colon-commands.

◈

Cursor Trail

Optional animated cursor trail with braille rendering, configurable easing, glow, and opacity.
